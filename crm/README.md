# מערכת ניהול לקוחות והרצאות

מערכת לניהול לקוחות עסקיים שבה יחידת העבודה היא **הרצאה בתאריך, בשעה ובמקום** —
ולא "עסקה" מופשטת. מיועדת למרצים, מדריכים ונותני שירות שהתוצר שלהם הוא מפגש.

אפליקציית דפדפן סטטית, ללא שרת וללא התקנה. הנתונים נשמרים ב-`localStorage`
של הדפדפן, עם גיבוי ושחזור לקובץ JSON.

## הפעלה

פתחו את `index.html` בדפדפן, או הגישו את התיקייה משרת סטטי:

```bash
npx http-server -p 8080 .
# http://localhost:8080/crm/
```

בהרצה ראשונה נטענים נתוני הדגמה. לניקוי: `localStorage.removeItem('crm.lectures.v1')`.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | שלד הדף, סרגל ניווט ונקודות עיגון |
| `app.js` | מודל הנתונים, מנוע ההתראות, המסכים והטפסים |
| `styles.css` | עיצוב, כולל תמיכת RTL |

## המסכים

- **לוח בקרה** — הרצאות קרובות, הכנסה מובטחת, ומה שדורש טיפול היום.
- **הרצאות** — כל ההזמנות, עם סינון לפי סטטוס וחיפוש חופשי.
- **לקוחות** — כרטיס לקוח עם אנשי קשר, היסטוריה וסך הכנסות.
- **קטלוג** — רפרטואר ההרצאות. בחירה מהקטלוג ממלאת נושא, אורך ומחיר אוטומטית.
- **כספים** — גיול חובות ומעקב גבייה.

## שדות ההרצאה

מתי: תאריך, שעת התחלה, משך. איפה: מקום מדויק, כתובת, איש קשר בשטח.
בנוסף: מספר משתתפים, ציוד נדרש, מחיר, החזר נסיעות, מספר הזמנת רכש, תאריך חיוב והערות.

## צינור הסטטוסים

```
ליד ← הצעה נשלחה ← מאושר ← בוצע ← חויב ← שולם
```

כפתור הקידום בכרטיס ההרצאה מעביר לשלב הבא. מעבר ל"חויב" מסמן אוטומטית
את תאריך החיוב, שממנו נגזר יעד התשלום לפי תנאי התשלום של הלקוח.

## מנוע ההתראות

ההתראות נגזרות מהנתונים הקיימים ואינן דורשות הזנה ידנית:

- הרצאה מאושרת בתוך 10 ימים אצל לקוח שדורש הזמנת רכש, ללא מספר הזמנה.
- הרצאה שתאריכה עבר וטרם עודכנה כבוצעה.
- הרצאה שבוצעה וטרם חויבה.
- תשלום שחרג מתנאי התשלום של הלקוח.
- הצעת מחיר שטרם אושרה כשההרצאה מתקרבת.
- לקוח שהזמין בתקופה הזו בשנה שעברה ולא הזמין מאז חצי שנה.
